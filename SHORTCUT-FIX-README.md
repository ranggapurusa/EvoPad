# EvoPad — Pemetaan Gesture 3 dan 4 Jari

Pemetaan mengikuti konfigurasi yang diminta:
- 3 jari: drag dengan menahan klik kiri selama ketiga jari bergerak.
- 4 jari swipe atas: Mission Control (Control + Up).
- 4 jari swipe bawah: App Exposé (Control + Down).
- 4 jari swipe kiri/kanan: pindah Spaces (Control + Left/Right).

Gunakan `README-ID.md` untuk langkah instalasi dan pengujian lengkap. Shortcut empat jari dapat diuji langsung dari tombol `Tes` di Mac Helper.
